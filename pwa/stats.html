🔴 P0 · 做题习惯 先改这个

——不是能力问题，是做题习惯。改 3 个动作，细节题至少能少错一半。

  • 细节题手指定位：做每道 According to Para X 题时，用笔/手指在原文里指到该段，逐句读完再选。
  • 人物名题先圈人名：题干出现 X believes/holds/notes，先在草稿纸上写下人名，再回原文先找人名，不要先读选项。
  • 推理题看前后各一句：it can be inferred / by saying X implies 的题，永远读完引语句前一句和后一句再选。
  • 做完一道立刻回看题干：选完答案回题干问自己"我问的是这个吗？"。

🔴 P0 · 主旨题抢救 常见全错区

  • 每篇阅读先做主旨题，完成后再做细节/推理。
  • 扫每段第 1 句，写 5 个关键词在草稿纸上（每段 1 个）。
  • 找出现 ≥3 次的词作为主旨候选。
  • 排除"段意型"（只覆盖一段）、"以偏概全型"选项。
  • 在 错题本 顶部按题型刷「主旨题」。

🟡 P1 · 词义题同义改写

  • 每道词义题先口述原句意思，再选答案。
  • 排除"字面相似但改写过头的"选项（把"情绪"改成"想法"就不是同义）。
  • 英一 + 英二词义题集中刷，见 错题本。

🟢 P2 · 人物观点混

  • 题干出现 X believes/holds/argues/most likely agrees —— X 是谁先圈出来。
  • 回原文找 X 出现的那句，只信那句话，不要被其他段落里相似词带走。
